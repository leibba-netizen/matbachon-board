# 🧽 מד המטבחון — לוח הניקיון המשותף

אתר עמוד-יחיד (`index.html`) לניהול מטבחון משותף: דירוג ניקיון, תורנים והזמנות, דיווח תקלות, ומשחקים עם מערכת שחקנים.

## 🔴 האתר חי כאן

לאחר הפעלת GitHub Pages, הכתובת החיה תהיה:
`https://<שם-המשתמש>.github.io/<שם-המאגר>/`

כל פעם שדוחפים (`push`) שינוי ל-branch הראשי, GitHub Pages בונה ומפרסם מחדש אוטומטית תוך כדקה.

## ⚠️ שלב חובה: חיבור Firebase (כדי שהנתונים יהיו משותפים לכולם)

כרגע האתר עובד ב**מצב מקומי בלבד** — כל דפדפן רואה רק את הנתונים שלו, בלי סנכרון. כדי שדירוגים, תורנים, תקלות ושיאי משחקים יתעדכנו **בזמן אמת אצל כולם**, יש לחבר פרויקט Firebase חינמי (פעם אחת, כ-5 דקות):

1. גשו ל-[console.firebase.google.com](https://console.firebase.google.com/) והתחברו עם חשבון Google.
2. **Add project** → תנו שם (למשל `matbachon-board`) → אפשר לכבות Google Analytics → **Create project**.
3. בתפריט הימני: **Build → Firestore Database → Create database**.
   - בחרו **Start in production mode**.
   - בחרו מיקום שרת (כל מיקום קרוב מספיק) → **Enable**.
4. בלשונית **Rules** של Firestore, החליפו את התוכן בזה ולחצו **Publish**:
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /kitchen2/{docId} {
         allow read, write: if true;
       }
     }
   }
   ```
   > הערה: הכלל הזה פתוח לקריאה/כתיבה לכל מי שיש לו את קישור האתר — תואם לאופי האתר המקורי (בלי התחברות/הרשאות ברמת המשתמש, כולל דיווח תקלות אנונימי). זה **לא** מתאים לנתונים רגישים.
5. חזרה למסך הראשי → סמל גלגל השיניים ⚙️ → **Project settings** → גללו ל-**Your apps** → לחצו על סמל ה-Web `</>` → תנו כינוי כלשהו → **Register app**.
6. יופיע אובייקט `firebaseConfig` — העתיקו אותו.
7. פתחו את `index.html`, חפשו את `FIREBASE_CONFIG` (קרוב לתחילת תגית ה-`<script>`), והדביקו את הערכים שלכם במקום `"YOUR_API_KEY"` וכו'.
8. שמרו, `git commit` ו-`git push` — האתר יתעדכן אוטומטית ויעבור למצב "מסונכרן בזמן אמת".

עד שהשלב הזה לא בוצע, יופיע חיווי "⚠️ מצב מקומי בלבד" בפינה השמאלית התחתונה של האתר.

## 📁 קבצי דמויות

`איגור.png`, `איזגי.png`, `סגל ביסט.png` הן תמונות הדמויות במסך בחירת הדמות של המשחקים. הן חייבות להישאר באותה תיקייה עם `index.html` כדי שהנתיבים היחסיים בקוד ימשיכו לעבוד.

## 🔄 פיתוח / בדיקה מקומית

אפשר לפתוח את `index.html` ישירות בדפדפן (לחיצה כפולה) לבדיקה מהירה — הפיצ'רים המקומיים (משחקים, פרופיל) יעבדו גם בלי Firebase; רק הסנכרון בין משתמשים דורש את החיבור.

## 🚀 פריסת עדכונים

כל שינוי בקוד: `git add . && git commit -m "..." && git push` — GitHub Pages יבנה מחדש אוטומטית.
